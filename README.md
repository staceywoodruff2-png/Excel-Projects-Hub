 Project overview: 
     The goal of this project was to take a large list of individual customer records (such as bike buyers) and turn it into a clean, visual report. The final         workbook is organized into four distinct sheets: Raw Data, Data Cleaning, Pivot Tables, and the final Dashboard.
 
 Skills applied: 
       Data cleaning: Finding and fixing mistakes, duplicates, and messy text in a giant list of data so it is accurate.
       Logical formulas: Using Excel formulas to automatically group numbers into helpful categories. 
       Summarizing data: Taking thousands of rows of individual data and squishing them down into simple, easy-to-read summary tables. 
       Dashboard layout: Making the final page look clean, organized, and easy for anyone to understand at a glance.
       
 Actions executed: 
       1. Data cleaning and preparation. 
          Removed duplicates: Found and deleted identical rows of data so nothing was counted twice.
          Fixed text mistakes: Used Find & Replace to fix typos and make words consistent (like changing "M" to "Married" and "S" to "Single").
          Created brackets with IF statements: Used Excel formulas (like IF functions) to automatically group data. For example, turning exact ages like 34 or 55             into clean categories like "Middle Age" or "Old".
       2. Pivot Tables and charts
          Built Pivot Tables: Created summary tables to automatically add up and calculate things like average income or total sales based on different                       categories.
          Created Pivot Charts: Turned those summary tables into visual charts (like line graphs and bar charts) to show trends and comparisons clearly.
       3. Interactive dashboard construction: 
          Arranged the layout: Placed the charts neatly on a dedicated sheet and turned off gridlines to make it look like a professional app instead of a                    spreadsheet.
          Added Slicers: Put in clickable buttons (like Region or Education) that let a user filter the entire page with one click.
          Connected the filters: Linked those slicers to all the charts at once so the whole dashboard updates together instantly.

 Data scope: 
     The project processed thousands of rows of customer transactions. Key data categories contained in the dataset include:
         Customer demographics: Background details like age brackets, marital status, gender, and income.
         Purchasing habits: Tracking customer details such as commute distance, region, and whether or not they chose to buy a bike.
